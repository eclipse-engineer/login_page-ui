# Login Page UI

A simple and responsive login page built using HTML and CSS.

## Features
- Clean and minimal design
- Email and password fields with built-in validation
- Hover effect on the login button
- Centered layout that works on all screen sizes

## Tech Stack
- HTML5
- CSS3

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
